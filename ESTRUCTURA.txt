SISTEMA DE GESTIÓN DE INVENTARIO Y TICKETS
==========================================

Este proyecto es un sistema local de gestión de inventarios y tickets de soporte técnico.
Está diseñado utilizando PHP nativo, MySQL y Vanilla JS, sin dependencias externas, ideal
para ejecutarse en entornos locales como Laragon, XAMPP o WAMP.

ESTRUCTURA DEL PROYECTO

INSTRUCCIONES DE DESPLIEGUE (Laragon)
-------------------------------------
1. Mover la carpeta a Laragon:
   - Copia la carpeta `Sistema-ticket` dentro de la carpeta `www` de tu instalación de Laragon
     (usualmente `C:\laragon\www\Sistema-ticket`).

2. Base de datos:
   - Abre HeidiSQL (botón "Base de datos" en Laragon) o phpMyAdmin.
   - Crea una nueva base de datos llamada: `gestion_bienes`
   - Selecciona la base de datos recién creada y ejecuta el script SQL ubicado en:
     `Sistema-ticket/sql/gestion_bienes.sql`

3. Configurar conexión:
   - Abre `config/db.php` y asegúrate de que las credenciales coincidan con tu servidor
     local (por defecto Laragon usa usuario 'root' y contraseña vacía '').

4. Ejecución:
   - Inicia los servicios de Apache y MySQL en Laragon.
   - En tu navegador, ingresa a: http://localhost/Sistema-ticket

5. Primeros pasos:
   - Crea un usuario "Administrador" usando el código secreto definido en `config.php`
     (por defecto es: INST2024ADMIN).
   - Inicia sesión y registra algunos bienes en el inventario.
   - Crea usuarios con roles de Operador y Técnico para probar el flujo de los tickets.
